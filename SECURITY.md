# Security policy

Report vulnerabilities through GitHub private vulnerability reporting when available. Do not publish real credentials, device keys, private topology details, production addresses, or sensitive configuration exports in an issue.

All credentials in this lab must be unique placeholders. Before committing Cisco output, remove enable secrets, password hashes, local usernames/passwords, RSA key material, SNMP communities, personal banners, and real syslog content. Preserve enough non-sensitive context for reviewers to understand the control.

This repository is an educational Packet Tracer simulation and offline triage example. It is not production network or SOC infrastructure.
